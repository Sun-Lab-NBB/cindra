Welcome to cindra API documentation page
========================================

Provides pipelines for processing neural imaging data and tracking Regions of Interest across multiple recordings.

This library is developed in the `Sun (NeuroAI) lab <https://neuroai.github.io/sunlab/>`_ at Cornell University. It
began as a fork of `suite2p <https://github.com/MouseLand/suite2p>`_ and has since been rewritten throughout. It
reimplements the suite2p single-recording pipeline, the multi-recording tracking method of the `OSM study
<https://www.nature.com/articles/s41586-024-08548-w>`_, and `pirt <https://github.com/almarklein/pirt>`_'s diffeomorphic
registration, and adds its own orchestration, parameter tracking, data caching, and agent interfaces.

This website contains the API documentation for the classes and methods offered by this library, together with the
reference for every command exposed by the 'cindra' and 'cindra-gui' command-line interfaces. See the project GitHub
repository for installation instructions and library usage examples:
`cindra GitHub repository <https://github.com/Sun-Lab-NBB/cindra>`_.
